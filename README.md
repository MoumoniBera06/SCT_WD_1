# SCT_WD_1 - Responsive Landing Page

## Coffee Shop Website

A clean, simple, and responsive coffee shop website built with vanilla HTML, CSS, and JavaScript. This frontend-only website features a modern design with a fixed navigation, hero section, about page, interactive menu, and contact form.

## 🚀 Features

- Fixed Navigation Bar - Smooth scrolling navigation with active section highlighting
- Responsive Design - Fully responsive layout that works on desktop, tablet, and mobile
- Interactive Menu - Filterable menu categories (Hot Coffee, Cold Drinks, Food)
- Contact Form - Working contact form with validation and user feedback
- Mobile Navigation - Hamburger menu for mobile devices
- Clean, minimalist design
- Simple color scheme with coffee-themed colors
- Hover effects and smooth transitions
- Grid-based layouts
- Typography optimized for readability

## Tech Stack

- HTML5
- CSS3 
- JavaScript (ES6)
